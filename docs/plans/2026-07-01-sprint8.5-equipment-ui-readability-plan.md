**Step 2: Implement.** In `AbilityTable`: build a `Dictionary<string, AbilityEntry> byId` inside `LoadFromJson` (clear alongside `AllAbilities`); add:

```csharp
public AbilityEntry GetById(string id)
{
    if (string.IsNullOrEmpty(id)) return null;
    return byId.TryGetValue(id, out var entry) ? entry : null;
}

public static string FormatDescription(AbilityEntry entry, float potency)
{
    if (entry == null || string.IsNullOrEmpty(entry.Description)) return "";
    return entry.Description.Replace("{potency}", potency.ToString("0.#"));
}
```

**New fields (replacing `StatSummary`):** `StatType PrimaryStat; int PrimaryValue; StatType SecondaryStat; int SecondaryValue; bool HasAbility; string AbilityName; string AbilityDescription; StatType AbilityStat; float AbilityPotency; int AbilityLevel; int AbilityMaxLevel; float AbilityXpFraction;`

**Signature:** `FromItem(EquipmentInstance item, int questLevel, AbilityTable abilityTable = null, EconomyConfig economy = null)` — existing call sites keep compiling.

**Rules:**
- Stat pair comes from `item.PrimaryStat/PrimaryValue/SecondaryStat/SecondaryValue` directly, NOT `GetTotalStatMods()` (fixes ability double-count in the summary)
- `AbilityName = table?.GetById(id)?.Name ?? item.Ability.AbilityId` (raw-id fallback per design)

- `AbilityXpFraction`: 1 when `Level >= MaxLevel`; else `CurrentXP / XPToNextLevel(economy.abilityBaseXPThreshold, economy.abilityXPGrowthRate)` clamped 0-1; 0 when economy null
- Keep static helpers `GetSlotName` / `GetRarityColor`; add `public static string StatLabel(StatType, int)` → `"CON +7"` and `public static string StatLabelColored(StatType, int)` using `StatTypeColors.GetColor` rich text (shared by card builder and detail panel)

Construct `EconomyConfig` via `ScriptableObject.CreateInstance<EconomyConfig>()`.

**Steps:** tests → implementation → interim call-site fixes (`data.StatSummary` → `ItemDisplayData.StatLabel(data.PrimaryStat, data.PrimaryValue) + "  " + ItemDisplayData.StatLabel(data.SecondaryStat, data.SecondaryValue)`) → compile check → commit `feat: restructure ItemDisplayData for stat pair + ability`.
